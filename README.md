Welcome to the repository for my website!

This website was designed for gamers who want to submit and write reviews for games. Users can also look up financial statistics about game publishers/developers.

A MySQL server was utilized to store the reviews, user details, and data. There are rudamentary security features, such as tracking cookies to make sure the user is valid and also a means to stop brute force logins.

I am unable to afford a server, so if you want to run the website on your own machine, you will need to download CanvasJS and store the files in the same directory as the HTML/PHP files.
